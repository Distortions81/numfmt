# Quantization Guide

This file is generated by `go test` (TestGenerateQuantizationGuide).

## How to Read This

- Exponent bucket: chooses coarse scale by powers of `base`.
- Mantissa levels: fine-grained steps inside each exponent bucket.
- Range mode: uses all non-zero codes across a chosen `[min,max]` interval.
- Range error table: log-binned average and worst-case relative error.
